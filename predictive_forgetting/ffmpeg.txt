# make one "output folder" per video, e.g. "video-1"; this is where your single frames will be stored
# the output folder has to be located in the "predictive_forgetting" folder

# change the line below to include your video file name (i.e. replace "video.mp4" with whatever your video is called. Make sure the video file name does not include any spaces

ffmpeg -i video.mp4 video-1/frame-%04d.jpg

# ffmpeg is calling the ffmpeg programme to execute everything behind it
# -i stands for "input", so "video.mp4" is the input the programme will be working with
# video-1 is the folder it will save the files to
# frame-%04.jpg is the filename it will use for the files. "%04" means it will save the files with four digits lead by zeros, so e.g. 0001, 0002 etc.
# .jpg tells it to save them as JPGs; you can also save them as .png (will use way more space and for this experiment there is absolutely no reason to do it)
