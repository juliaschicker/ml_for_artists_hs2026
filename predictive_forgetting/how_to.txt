PREPARATION OF THE FILES
1 – Split files with ffmpeg (see ffmpeg.txt) – make sure they are saved in the `predictive_forgetting` folder


TRAINING
2 - Set the training folder correctly in `train_predictve_forgetting.py`:
	On line 51, go to FRAMES_DIR = "training_frames"
	change "trainign_frames" to whatever the name of the folder is where you have your training footage
	Ideally, the folder has a few hundred files
3 - Set the name of the model, e.g. "predictive_forgetting_video_1", so you know what footage you trained it on (make sure you change the name every time, otherwise it will be overwritten)
4 - Save and close the file
5 - In your terminal, make sure you are in the "predictive_forgetting" folder (check the line before your cursor)
	If you are not there, type
	cd
	and then press tab. Select the path to your "predictive_forgetting" folder
	If you need to move one folder outside, type
	cd ..
	and hit enter, and you'll get to one folder above
6 - In your terminal, verify that (venv) is switched on.
	If that's the case, type
	python train_predictive_forgetting.py
7 - If the epochs pass very slowly, call me
8 - Voila, you have a model ready!


OUTPUT
9 - Open `wake_sleep_consolidate.py`
10- On line 44, set CHECKPOINT = "model.pt" to whatever name you gave your model before (i.e. exchange "model.pt" with "your-model-name.pt")
11- On line 46, set FRAMES_DIR = "folder" to whatever name the folder has, where the images you trained on are in
12- On line 48, set OUTPUT_DIR = "folder" to a folder you'll store your output images in (the folder will be created automatically; make sure it is a new one every time, otherwise it will be overwritten)
	Use names that make sense and maybe also let you know which model you used; otherwise this gets confusing very quickly
13- Go to your terminal, run
	python wake_sleep_consolidate.py
14- To create a video out of your files again, update the line below with your folder etc. and copy and run it in your terminal
	ffmpeg -framerate 25 -pattern_type glob -i 'folder/*.jpg' -c:v libx264 -pix_fmt yuv420p folder/out.mp4
15- You can now find your video!
